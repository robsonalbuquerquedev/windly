Aprenda **TailwindCSS**, **SEO moderno**, **HTML Semântico** e **boas práticas de Next.js** criando interfaces elegantes, rápidas e profissionais.  
O Windly é um projeto educacional e prático, feito para quem deseja construir páginas modernas seguindo padrões reais do mercado.

---

## ✨ O que é o Windly?

O **Windly** é uma plataforma que reúne:

- Conteúdo educacional focado em **TailwindCSS**, **Next.js**, **SEO**, **HTML semântico**, **Acessibilidade** e **Performance**.
- Exemplos reais usados em projetos profissionais.
- Páginas estruturadas com foco total em **boas práticas**, **semântica**, **componentização** e **UX**.
- Um **blog** dinâmico com conteúdos variados sobre tecnologia e desenvolvimento.

## 🎯 Objetivos do Windly

- Ensinar boas práticas modernas de desenvolvimento front-end.
- Demonstrar como construir páginas reais usando Next.js e Tailwind.
- Ajudar iniciantes e devs intermediários a criarem projetos profissionais.
- Guiar na criação de interfaces rápidas, acessíveis e bem estruturadas.

---

## 🔧 Como Rodar o Projeto

```bash
# Instalar dependências
npm install

# Rodar o servidor de desenvolvimento
npm run dev

# Build de produção
npm run build

# Pré-visualizar o build
npm start
```
